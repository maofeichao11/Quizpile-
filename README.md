**Quizpile（题堆）** —— 一个轻量的在线题库 / 刷题 / 组卷工具（类似考试宝的核心功能），**PHP + MySQL** 存储。

> 名字含义：Quiz（测验）+ Pile（堆），把题目像「题堆 / 柴堆」一样越积越多、随时取出来练，正合刷题和题库的场景，也暗合「题海战术」。

## 1. 运行方式

### 1.1 环境要求

PHP ≥ 7.2（需开启 `pdo_mysql`、`curl`、`zip`、`mbstring`、`openssl` 或 `allow_url_fopen`）+ MySQL 5.7 / 8.0。AI 导题库解析 docx/xlsx/pptx 需要 `zip` 扩展。

### 1.2 安装与启动

```bash
# 1. 获取代码
git clone <本仓库地址> exam && cd exam

# 2. 创建配置（仓库仅含示例，真实配置不入库）
cp lib/config.sample.php lib/config.php
#   编辑 lib/config.php，填入你的 MySQL 账号密码

# 3. 启动（PHP 内置服务器，临时调试用）
php -S 127.0.0.1:8080
```

浏览器打开 `http://127.0.0.1:8080/`，**首次访问会自动建库建表**，无需手动导入 SQL。
默认管理员账号 **admin / admin123**，登录后请立刻到「设置 → 修改我的密码」改掉。

> 提示：PHP 内置服务器是**单线程**的，AI 导题库解析大文档时会占住整个站点。长期使用建议换 Apache / Nginx 部署，配置见 **`deploy/README.md`**。需开启 `pdo_mysql` 扩展（phpstudy 默认已开启）。

<a id="db"></a>
## 2. 数据库配置（MySQL）

仓库里**不含** `lib/config.php`（它保存着账号密码，已被 `.gitignore` 忽略）。
第一次使用请从示例复制一份：

```
cp lib/config.sample.php lib/config.php
```

然后修改这几项：

```php
define('DB_HOST', '127.0.0.1');
define('DB_PORT', '3306');
define('DB_NAME', 'exam');   // 数据库名，首次访问自动创建
define('DB_USER', 'root');
define('DB_PASS', '');       // ← 改成你的 MySQL 密码（phpstudy 默认是 root）
```

首次打开页面时会自动创建数据库 `exam` 和 4 张表（banks / questions / records / exams），无需手动导入 SQL。

**常见问题**
- 页面提示「数据库连接失败」：确认 phpstudy 里 MySQL 已启动、端口和密码与 `config.php` 一致。
- 数据表迁移或重装：删掉 `exam` 数据库后刷新页面即可自动重建。

## 3. 用户、权限与题库市场

<a id="users-login"></a>
### 3.1 登录注册

- 首次打开会显示登录页，可切换「登录 / 注册」
- 所有接口都需要登录态，未登录会提示「请先登录」
- 忘记密码时用命令行重置：`php tools/set_password.php <用户名> <新密码>`

<a id="users-admin"></a>
### 3.2 管理后台（管理员）

管理员账号登录后，侧栏会出现「管理后台」，可以：
- **查看所有用户**：用户名、昵称、拥有的题库数、题目数、答题数、考试数、注册时间
- **查看某个用户拥有哪些题库**（包括他从市场添加的）
- **修改任意用户的密码**（新密码至少 6 位）
- **删除用户**（连带删除其上传的题库、题目、答题与考试记录，需二次确认；不能删自己）
- **管理全部题库**：打开任意题库（以可编辑身份）、设置分享/密码、删除题库
- 普通用户访问这些后台接口会被拒绝（服务端校验）

<a id="users-perm"></a>
### 3.3 题库权限

- 题库归属于**上传者本人**（`banks.owner_id`），只有本人可以：编辑/删除题库、导入题目、增删改题目
- 其他用户**可以练习、考试、查看**，但不能改动
- 答题记录、错题本、考试记录、统计都**按用户隔离**（A 的错题和正确率不会混进 B）
- 现有 `hcie` 题库已归属 `admin`；历史数据（题库/记录/考试）在启用用户体系时统一划到 admin 名下

<a id="users-market"></a>
### 3.4 题库市场

- 在自己的题库卡片上点「发布 / 分享设置」：可设**提取密码**（可留空）和简介
- 其他用户在「题库市场」看到已公开的题库，点「添加」（有密码时需输入密码）
- 添加后出现在对方「我添加的题库」里，**标记为只读**，归属仍属原上传者
- 上传者随时可以「取消发布」，或改密码；对方可以「移除」已添加的题库

<a id="images"></a>
## 4. 图片题用法

题干、选项、解析都支持图片，采用 Markdown 语法：`![说明](图片地址)`。

- **本地图片**：在题目编辑弹窗底部点「选择文件」→「上传并插入」（单个 ≤ 5MB，支持 jpg/png/gif/webp/bmp），图片存到 `uploads/年月/` 下，自动插入光标所在位置
- **外链图片**：填 `http(s)://` 开头的链接，点「插入链接」
- 纯文本批量导入时也可以直接写 `![](uploads/202609/xxx.png)`，JSON/CSV 导出会原样保留

<a id="ai"></a>
## 8. AI 导题库（推荐用于格式杂乱的历史题库）

题目里「批量导入」只认固定格式，而现实中大量题库是 Word / Excel / PPT，**排版各不相同**。这个功能把文档交给大模型去"读懂"，再转成标准题目。

<a id="ai-local"></a>
### 8.1 结构化内容先走本地解析（不消耗 AI）

**JSON / 带表头的 CSV** 这类本身就有结构的内容，会**先用本地规则精确解析**，命中就直接出结果，完全不会调用大模型 —— 又快又准又不花钱。只有"排版自由的 Word / PPT / 纯文本"才交给 AI。识别不出来时才回退到 AI。

<a id="ai-steps"></a>
### 8.2 使用步骤

1. **配置接口**（只需一次）：左侧「设置 → AI 导题库配置」，自己填写
   - 接口地址（Base URL）：OpenAI 兼容接口均可（输入框里有「如 https://...」示例提示）
   - API Key：你自己的 Key（输入框里只有「如 ark-xxxxxxxx」示例提示）
   - 模型名：你自己的模型（输入框里只有「如 deepseek-...」示例提示）
   - 点「测试连接」确认可用，再「保存配置」

   > **没有内置默认值**：三项都要自己填，接口地址/模型名/Key 缺任何一项都会明确提示
   > 还缺什么（「AI 导入」被点击时也会提示"当前还缺：xxx"并引导去设置）。
   > **配置是按账号隔离的**：存在各自的 `users.settings` 里，接口不接受任何 user 参数，
   > 谁也读不到、改不了别人的配置；管理后台也不返回任何人的 Key。
   > **Key 只单向写入**：保存后不再回显原文（页面只显示"已配置/未配置"），
   > 留空保存＝保持原 Key 不变，要删除请点「清除 Key」。
2. 进入某个题库 → 右上角 **✨ AI 导入**（未配置接口时会提示前往设置）
3. 上传文件（或直接把文字粘贴到输入框）→ **开始解析**
   - 解析过程有 **⏱ 计时器 + 实时进度条 + 滚动日志**（每块提交/完成耗时、得到多少题、比对结果都记在日志里）
   - 单块解析若因网络中断失败会**自动重试 3 次**，不会整批白跑
4. **解析预览与比对**：逐题展示题型、题干、选项、答案、解析；并自动与题库已有题目比对
   - `疑似重复`（题干完全一致或高度相似，附已有题目原文，可看出差异）
   - `答案存疑`（原文没给出答案）
   - 重复项与存疑项**默认不勾选**，可逐一勾选/取消；支持「全选 / 全不选 / 只选非重复」
5. **确认导入** → 第三步列出本次导入的题目，可与原文档逐条核对；随后到题目列表可继续编辑

<a id="ai-formats"></a>
### 8.3 支持的格式

| 格式 | 说明 |
| --- | --- |
| `.docx` | 按段落、表格提取文字（保留换行/制表） |
| `.xlsx` | 读取共享字符串与各工作表，按行列还原 |
| `.pptx` | 逐页提取文本框文字 |
| `.txt` / `.csv` / `.tsv` / `.md` / `.json` / `.html` | 自动识别编码（UTF-8 / GBK 都能正确读中文） |
| 直接粘贴 | 任意排版文字都行 |
| `.doc` / `.xls` / `.ppt` | **不支持**，请先另存为 `.docx` / `.xlsx` / `.pptx` |
| `.pdf` | **不支持**（纯 PHP 无法可靠取文本），请转 Word 或直接粘贴文字 |

- 单文件 ≤ 30MB；单次最多解析约 60 万字（超出会提示只处理前 60 万字，建议拆分）
- 解析按 **2400 字一块**逐块请求（块小 → 单次更快、更不容易被中断）；每块失败会自动重试 3 次
- 接口被设计成**任何情况下都返回 JSON**：PHP 告警/致命错误也会转成 `{"ok":false,"error":"..."}`，不会再把 HTML 错误页丢给前端（前端也做了兜底提示）
- 识别规则：题号不进题干、选项自动编号、"答案：/参考答案/正确答案"自动对应、`对/错` 自动识别为判断题、答案给了中文（如"乙"）会自动映射回选项字母
- 答案无法确定时标记 `答案存疑` 并不预先勾选，避免把错答案静默入库

<a id="ai-api"></a>
### 8.4 相关接口

| action | 说明 |
| --- | --- |
| `ai_config` | 读取当前用户的 AI 配置（只回 `base`/`model`/`has_key`/`ready`/`missing`，**不回传 Key 原文**，也不回默认值） |
| `ai_config_save` | 保存接口地址 / Key / 模型名；Key 单向写入（留空=不修改，`clear_key=1` 才清除） |
| `ai_config_test` | 测试连接是否可用 |
| `ai_extract` | 上传文件（multipart）或粘贴文本 → 提取文字；若命中 JSON/CSV 则直接返回 `local:true` + `items`（不调 AI），否则切块返回 `token` |
| `ai_parse_chunk` | 按 `token` + 块序号调用模型解析，返回归一化后的题目 |
| `ai_compare` | 与指定题库已有题目比对，返回疑似重复项 |
| `import_commit` | 复用原导入接口，把勾选的题目入库 |

<a id="import"></a>
## 9. 批量导入格式

<a id="import-text"></a>
### 9.1 纯文本（推荐，直接粘贴）

```
【单选】中国的首都是哪个城市？
A. 上海
B. 北京
C. 广州
D. 深圳
答案：B
解析：常识题

【多选】以下哪些属于一线城市？
A. 北京
B. 上海
C. 拉萨
D. 深圳
答案：ABD

地球是圆的。
答案：对

中国的全称是____。
答案：中华人民共和国
```

规则：
- 以「答案：」开头的行为本题答案；答案之后再出现新内容即视为下一题（无需题号）
- 选项写作 `A. xxx`、`A、xxx` 或 `(A) xxx`
- 不写题型标记时自动判断：有选项且有 2 个以上答案 → 多选；有选项 → 单选；答案是「对/错/正确/错误」→ 判断；否则 → 填空
- 判断题可选写法：`答案：对` / `答案：错误` / `答案：A`（A=正确，B=错误）
- 填空题多个空用 `|` 分隔：`答案：北京|北平`
- 可选附加行：`解析：xxx`、`标签：xxx`

<a id="import-csv"></a>
### 9.2 CSV（每个选项一个单元格，Excel / WPS 可编辑）

```
题型,题干,A,B,C,D,答案,解析,标签,章节
单选,1+1=?,1,2,,,B,基础算术,数学,第一章
多选,以下哪些是偶数？,2,3,4,,AC,,数学,第一章
判断,地球是圆的。,正确,错误,,,A,,常识,第二章
填空,中国的首都是____。,,,,,北京,,地理,第二章
简答,简述 TCP 三次握手。,,,,,SYN → SYN/ACK → ACK,,网络,第三章
```

规则：
- **每个选项占一个单元格**：A 列 = 选项 A，B 列 = 选项 B……用不到的留空（也可加 E、F 列）
- **答案**：单选 `B`，多选 `AC`（字母连写），判断 `A`=正确 / `B`=错误，填空/简答直接写文字
- 列顺序随意，中英文表头都认（`题型/题干/A/B/C/D/答案/解析/标签` 或英文 `type/stem/...`），可加 `章节`
- 判断题：A、B 列填 `正确`、`错误`（或 `对`、`错`）会自动识别为判断题
- **不写题型也能自动判断**；`解析`、`标签`、`章节` 在最后，可以整列省略
- ⚠️ 每行至少要填到「答案」列，中间空列也要保留逗号，否则后面的列会往前串位
- 保存编码选 **UTF-8（带 BOM）**，避免中文乱码

<a id="import-json"></a>
### 9.3 通用 JSON

{
  "questions": [
    {

      "options": {"A": "1", "B": "2"},

<a id="security"></a>
## 11. 安全与运维

<a id="security-hardening"></a>
### 11.1 安全加固

- **CSRF 校验**：除登录/注册外，所有接口需带 `X-CSRF-Token`（登录后由 `me` 接口下发）
- **登录限流**：同一账号+IP 连续错 5 次锁定 10 分钟（15 分钟内累计）
- **上传目录禁执行**：`uploads/.htaccess` 禁止 PHP 执行与目录列表；Nginx 用户见 `uploads/README.md`
- 密码用 bcrypt 存储；支持用户自助改密码（需验证原密码）

<a id="security-tests"></a>
### 11.2 自动化测试

**后端接口回归（44 项）**
```
TK_ADMIN_PASS=<管理员密码> php tests/api_smoke.php http://127.0.0.1:8088/api.php
```

## 12. 常见问题

- **页面提示「数据库连接失败」**：见「2. 数据库配置」，先确认 MySQL 已启动、账号密码端口正确。
- **插入的图片不显示**：确认图片已成功上传（`uploads/` 下有文件），或用能公网访问的外链。
- **图片上传失败**：检查单个文件 ≤ 5MB，且 `uploads/` 目录有写权限。
- **导入解析不到题目**：检查是否有「答案：」行，没有答案的题目会被跳过。
- **想清空重来**：删掉 MySQL 里的 `exam` 数据库，刷新页面即自动重建。
- **AI 导入提示「缺少 zip 扩展」**：在 php.ini 里打开 `extension=zip`（解析 docx/xlsx/pptx 需要）。
- **AI 导入中途失败并提示"服务器返回异常页面"**：多半是单次请求耗时过久被中断，
  换 Apache/Nginx 部署、或把文档拆小一些再解析（内置 PHP 服务器是单线程，最容易撞到）。
