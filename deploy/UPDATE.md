# Quizpile 代码更新流程（不动数据）

数据只有两处：**MySQL 数据库** 和 **uploads/ 图片目录**。
其余都是代码文件，可以直接覆盖。数据库结构由程序自动升级（首次访问时执行 `migrate()`：建表用 `IF NOT EXISTS`、加字段用 `add_column_if_missing`），
所以**新版代码覆盖后不用手工执行任何 SQL**。

## 一、可以覆盖的文件（每次更新都传）

| 文件 / 目录 | 说明 |
| --- | --- |
| `index.php` | 页面入口 |
| `api.php` | 接口 |
| `lib/db.php`、`lib/auth.php`、`lib/question.php` | 数据层 / 权限 / 解析 |
| `assets/app.js`、`assets/style.css` | 前端 |
| `tools/`、`tests/`、`deploy/` | 运维与测试脚本 |
| `uploads/.htaccess` | 安全规则（Nginx 无效，可传可不传） |

## 二、绝对不要覆盖 / 不要删的

| 文件 / 目录 | 原因 |
| --- | --- |
| ⚠️ **`lib/config.php`** | 里面是**服务器上的数据库账号密码**。本地那份是 `root/root`，覆盖上去会直接连不上数据库 |
| `uploads/` | 用户上传的题目图片，覆盖了就丢图 |
| 任何 `phpMyAdmin*` 目录 | 不该放在站点目录下 |

> 更新时最省事的做法：本地打包 → 上传解压 → **删掉压缩包里的 `lib/config.php`** 再覆盖，
> 或者覆盖后把服务器上的 `lib/config.php` 改回正确的账号密码。

## 三、推荐更新步骤

1. **备份**（10 秒的事）
   - 宝塔 → 网站 → 备份（或打包 `/www/wwwroot/你的站点`）
   - 宝塔 → 数据库 → 导出
2. **本地打包**：把 `exam/` 里除 `phpMyAdmin*` 外的文件打成 zip，**从包里删掉 `lib/config.php`**
3. **上传覆盖**：宝塔 → 文件 → 进站点根目录 → 上传 zip → 解压覆盖（**不要**先删旧文件）
4. **重载 / 清缓存**：Nginx 一般不用重载；浏览器 `Ctrl+F5` 强刷（静态资源带版本号参数，会自动取新文件）
5. **验证**
   ```bash
   php tests/api_smoke.php http://你的域名/api.php
   ```
   结尾显示「通过 44 项，失败 0 项」即正常。再打开页面点几个功能确认。

## 四、出问题怎么回滚

把第 1 步的目录备份解压回去即可（数据库没动过，不用还原）。
如果**更新涉及数据库结构变化**且回滚旧代码，旧代码只是忽略新增字段，不会报错。

## 五、需要搬数据的场景（不是纯代码更新时才做）

| 场景 | 做法 |
| --- | --- |
| 换服务器 | 导出 MySQL → 新服务器导入 → 拷 `uploads/` → 传代码 → 改 `lib/config.php` |
| 只想同步题库 | 用「导出 → JSON」再在新环境导入（图片需另外拷 `uploads/`） |
| 只加图片 | 单独传 `uploads/` 下的新文件即可 |
